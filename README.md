# ☀️ SolarIQ Egypt

An AI-powered sustainability analytics platform that leverages solar, weather, and air quality data to support renewable energy planning, agriculture, construction, and tourism decision-making across Egypt.

## 🚀 Features

* Solar Site Ranking & Investment Scoring
* Weather & Air Quality Analytics
* 15 Interactive Power BI Dashboards
* 5 Interactive Tableau Dashboards
* SSRS Reporting System
* Azure SQL Cloud Integration
* Automated ETL Pipelines
* Streamlit Web Application
* AI-Ready Decision Support Framework

## 📊 Data Sources

* NASA POWER API
* Open-Meteo Weather API
* Open-Meteo Air Quality API
* Geographic & Climate Datasets

## 🏗️ Architecture

```text
Data Sources
     ↓
 Bronze Layer
     ↓
 Silver Layer
     ↓
  Gold Layer
     ↓
SQL Server / Azure SQL
     ↓
Power BI • SSRS • Streamlit
```
